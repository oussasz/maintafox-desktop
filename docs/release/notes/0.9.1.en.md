**Maintafox 0.9.1: test version, for internal test PCs only**

This update fixes what the first hands-on test of 0.9.0 found. Please still don't use it with real plant data.

Fixed:
- **First administrator:** the administrator created on the first-start screen signs in with the password they just chose. They are no longer asked to change it straight away. The same applies to an administrator created with a vendor recovery code. Accounts created by an administrator still change their password at first sign-in.
- **Sign-in on a French Windows:** the first sign-in on a PC was refused as "offline" on a French-language Windows. It now works whatever the Windows language.
- **Black window flashing:** opening a module no longer flashes a black command window.
- **Screens before sign-in:** activation, sign-in, recovery code, forgotten password, update and start-up screens now scroll, so nothing is cut off on a small screen or with display zoom at 125–150 %.
- **Menu and printing:** links in the side menu always open in the main window, never in a second window. Work orders, permits, the organisation export and request approval sheets now print from the main window.

Please report anything that looks wrong, with the screen and the time it happened.
