**Maintafox 0.9.0: test version, for internal test PCs only**

This is the first installer of Maintafox for testing on your own PCs before any plant uses it. Please don't use it with real plant data yet.

What to try:
- **Maintenance work:** work requests, work orders from planning to close-out, preventive maintenance plans, inspection rounds and reliability analysis.
- **Safety:** work permits, lock-out/tag-out (LOTO) with isolations, and the safety checks before work can start.
- **Equipment and stock:** assets, spare parts, stock movements and stock counts.
- **Organisation:** sites, teams, people, skills and rights by site. The reference lists are maintained in one place, "Reference data".
- **Several PCs:** changes are shared between PCs, with conflicts shown for review.
- **Administration:**
  - the licence;
  - backups and restores;
  - a vendor recovery code that creates one new administrator if every administrator is lost.
- **Updates:** this version can update itself. Before installing an update it backs up your data. If the update fails, it puts the previous version back on that backup.

Please report anything that looks wrong, with the screen and the time it happened.
