# Release notes

One pair of files per version: `<version>.en.md` and `<version>.fr.md` (for example `1.2.0.en.md`
and `1.2.0.fr.md`). The release workflow refuses to build without both. Users see them before
they install; they can be edited later in Console > Updates > Releases. Write for the people using
Maintafox: what changes for them, in a few short lines.
